> 🧼 **MetaStrip** is the cross-platform answer to photo metadata: one codebase
> that runs as a desktop app on macOS, Windows and Linux — or as a self-hosted
> web server for a team.

Same problem as **VisualExif** (VC-006), different shape. Where that one is a native
macOS app, MetaStrip trades native feel for reach: a single Node core, wrapped
either in Electron or in Express.

---

## ⚙️ Two Shells, One Core

```
                   ┌─────────────────────────┐
                   │        CORE API         │
                   │  sharp + exifr          │
                   │  ├─ POST /api/read      │
                   │  └─ POST /api/strip     │
                   └───────────┬─────────────┘
                               │
              ┌────────────────┴────────────────┐
              ▼                                 ▼
   ┌────────────────────┐            ┌────────────────────┐
   │  ELECTRON SHELL    │            │   EXPRESS SERVER   │
   │  macOS/Win/Linux   │            │   self-hosted      │
   │  🔒 local only     │            │   👥 team access   │
   │  files never move  │            │   ⚠️ needs HTTPS   │
   └────────────────────┘            └────────────────────┘
```

> ⚠️ **The two modes have different threat models and must say so.** Desktop
> mode never moves your files. Server mode sends images over the network — fine
> on a LAN behind HTTPS, wrong for genuinely sensitive material. The UI must
> not pretend these are the same.

## 🧩 Presets

| Preset | Removes | Keeps | For |
|---|---|---|---|
| 🔒 **Privacy Mode** | GPS, author, device, serial | Camera settings, ICC, orientation | Posting publicly |
| 🧹 **Full Clean** | Everything non-essential | ICC, orientation | Maximum anonymity |
| 🎛️ **Custom** | Per-category toggles | Your choice | Knowing exactly what you want |

ICC profile and orientation are **never** removed — stripping them produces
sideways, colour-shifted images, which reads as a bug no matter how well it is
documented.

## 🏗️ Stack

| Layer | Choice | Why |
|---|---|---|
| Read | `exifr` | Fast, thorough metadata parsing |
| Write | `sharp` | libvips — strips while re-encoding cleanly |
| API | Express | Two endpoints is all this needs |
| UI | React — DropZone, MetadataViewer, CriteriaPanel, ResultsPanel | |
| Batch | JSZip | Download a whole batch as one file |
| Desktop | Electron | One shell, three platforms |

**Limits:** up to 100 files per batch, 100 MB each.

## ⚠️ Risks

- 🌐 Server mode over plain HTTP leaks the very data the tool exists to remove
- 🖼️ TIFF support is limited by what `sharp` handles
- 📷 No RAW formats in v1 — say so plainly rather than failing silently
- ✍️ Signing and notarization are the difference between "downloads" and "installs"

---

## ✅ Definition of Done

A Windows user installs a signed `.exe`, drags in 50 photos, picks Privacy
Mode, and downloads a ZIP of clean images that still open the right way up
with correct colour.
