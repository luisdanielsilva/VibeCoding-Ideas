## The Core Question

DealScope answers what every property buyer wants to know: given this specific property at this price, which investment strategy generates the best returns — and how sensitive are those returns to changes in your assumptions?

## Four Investment Strategies Modeled Side-by-Side

- **Short-term rental (Airbnb):** nightly rates, occupancy patterns, platform fees, cleaning, utilities, furnishings, licensing
- **Long-term rental:** monthly rent, vacancy risk, tenant defaults, property tax, condo fees, insurance, maintenance reserves
- **Buy-renovate-resell:** timeline-based analysis of purchase → renovation costs → holding costs → sale, with capital-gains tax
- **Off-plan assignment:** buying pre-completion and selling the contractual position to another buyer, measured against actual deposits rather than full price

## Single Unified Model

All four strategies run through one shared financial engine that handles acquisition costs, transfer tax, mortgage terms and investor tax profile identically across every scenario. This ensures honest comparison.

## Range-Based Analysis (Not Point Estimates)

- Pessimistic, base and optimistic cases run in parallel
- Tornado charts show which assumptions actually drive the outcome
- Optional Monte Carlo simulation shows the probability the deal hits your return target
- Commonly reveals that base-case favorites become worst performers under downside assumptions

## The Comparables Engine

The innovation: DealScope automatically fetches comparable properties on the same streets using rule-based matching (location, typology, area, condition, listing date). This grounds all assumptions in real local market data rather than guesses.

## Key Metrics Across All Strategies

Net yield, cash-on-cash return, IRR, NPV, payback period, equity multiple, and strategy-specific break-even points (occupancy rate, monthly rent, resale price).

## Output: Professional PDF Report

- Full assumption set and data sources
- Strategy comparison table
- Per-scenario cash-flow waterfalls
- Sensitivity charts and break-even analysis
- Plain-language verdict with conditions (e.g. *works as LTR at asking price, works as STR only above 65% occupancy*)

## Two Distinct User Bases

- **Estate agents:** advisory tool to educate clients with data rather than photos
- **Buyers:** negotiating ammunition — comparables ranked by price, competing offers, asking-price percentile

## Business Model: Truly Free

- No paywalls, no blurred features, no account required to run analysis
- Optional donation button appears only after the report is generated
- Optional account exists solely to store past analyses, never a requirement

## Data Governance

- Stores all analyses with full privacy controls
- Applies retention windows rather than indefinite storage
- Separates identifying data from deal metrics so aggregate market insights can be published without exposing individuals
- Respects deletion requests as a working feature

## Jurisdiction-Specific Rules

Tax and regulatory parameters (transfer tax, capital gains, rental income rules, licensing) are configurable per location and update with legal changes.

## Design Philosophy

The tool shows all its work: every assumption is visible, sourced and editable. It is explicitly a modeling aid, not financial advice, designed so professionals can challenge specific numbers rather than trusting a black-box conclusion.
