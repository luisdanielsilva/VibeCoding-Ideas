> 🔀 **DrawIO → Mermaid** turns a binary diagram into text you can commit,
> diff and review — diagrams as code, without redrawing anything.

A diagram in a repo is usually a PNG nobody can edit or a `.drawio` file Git
sees as one opaque blob. Either way, "what changed in this diagram?" has no
answer. Mermaid is text: greppable, diff-able, reviewable in a pull request.
This converts one into the other.

---

## ⚙️ How It Works

```
  .drawio file
      │
      ▼
  ┌─────────────────────┐
  │ 1. Detect encoding  │  raw XML ─or─ deflate+base64 blob
  └──────────┬──────────┘
             ▼
  ┌─────────────────────┐
  │ 2. Inflate & parse   │  → mxGraphModel tree
  └──────────┬──────────┘
             ▼
  ┌─────────────────────┐
  │ 3. Classify cells    │  vertex? edge? group? label?
  └──────────┬──────────┘
             ▼
  ┌─────────────────────┐
  │ 4. Infer node shape  │  style string → rect/diamond/round/cylinder
  └──────────┬──────────┘
             ▼
  ┌─────────────────────┐
  │ 5. Resolve edges     │  source/target ids → node ids
  └──────────┬──────────┘
             ▼
  ┌─────────────────────┐
  │ 6. Pick diagram type │  flowchart · sequence · class · ER
  └──────────┬──────────┘
             ▼
  ┌─────────────────────┐
  │ 7. Emit Mermaid      │  + report anything unmapped
  └─────────────────────┘
```

> 💡 Step 7 is the trust mechanism. A converter that silently drops shapes is
> worse than one that refuses: **always emit a list of what didn't map.**

## 🧩 The Translation Table

| DrawIO | Mermaid | Note |
|---|---|---|
| Rectangle | `A[Text]` | Default |
| Rounded rectangle | `A(Text)` | From `rounded=1` |
| Diamond / rhombus | `A{Text}` | Decision node |
| Ellipse / circle | `A((Text))` | |
| Cylinder | `A[(Text)]` | Database |
| Solid edge | `A --> B` | |
| Dashed edge | `A -.-> B` | From `dashed=1` |
| Labelled edge | `A -->\|label\| B` | |
| Container / swimlane | `subgraph` | Nesting is the hard part |
| Custom shape library | ⚠️ unmapped | Report, don't guess |

## 🏗️ Stack

| Layer | Choice | Why |
|---|---|---|
| Parser | Node + `fast-xml-parser` | mxGraphModel is plain XML once inflated |
| Decompression | `pako` (deflate) | DrawIO compresses by default |
| Preview | `mermaid.js` | Render the output live, beside the input |
| UI | Split-screen web page | Paste left, Mermaid right |
| CLI | Same core, thin wrapper | Git hooks and CI need no browser |

The parser core must be a **library first**, with the web UI and the CLI both
consuming it. Two implementations will drift.

## ⚠️ Risks

- 🎨 **Styling will be lost.** Mermaid has no equivalent for arbitrary colours and fonts. Decide up front that layout and structure convert, decoration does not.
- 🪆 **Nested groups are genuinely hard.** DrawIO nests freely; Mermaid `subgraph` does not. Flatten deep nesting and say so.
- 🧩 **Custom shape libraries can't map 1:1.** Fall back to a rectangle plus a warning.
- ↔️ Reverse conversion is a second product, not a flag.

---

## ✅ Definition of Done

A developer drops a `.drawio` file in, gets Mermaid that renders as
recognisably the same diagram, sees an explicit list of anything that didn't
translate, and can run the identical conversion from a pre-commit hook.
