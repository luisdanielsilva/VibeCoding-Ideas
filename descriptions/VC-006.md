> 🕵️ **VisualExif** shows you exactly what your photos are telling strangers —
> then removes precisely what you choose. Native macOS, fully offline.

Every photo you share carries a hidden passenger: GPS coordinates down to the
doorstep, a device serial number, the exact second it was taken, sometimes your
name. VisualExif makes that visible and gives you surgical control over it.

---

## 🎯 What's Actually In Your Photo

| Category | Contains | Risk |
|---|---|---|
| 📍 GPS | Latitude, longitude, altitude | 🔴 Your home address |
| 📷 MakerNotes | Camera serial, lens, shutter count | 🟠 Device fingerprint |
| 🕐 EXIF | Timestamps, exposure, orientation | 🟡 Pattern of life |
| ✍️ IPTC / XMP | Author, copyright, keywords, edits | 🟠 Identity |
| 🎨 ICC | Colour profile | 🟢 Keep — removing it wrecks colour |

> ⚠️ **Never strip blindly.** Orientation and colour profile must survive, or
> cleaned photos come out sideways and washed out. "Remove everything" must
> still mean "remove everything *except* what makes the image render correctly."

## ⚙️ How It Works

```
   drag file(s) in
        │
        ▼
  ┌──────────────────┐
  │ bundled ExifTool │  no install, no PATH, no Homebrew
  └────────┬─────────┘
           ▼
  ┌──────────────────┐
  │ parse → category │  GPS · EXIF · IPTC · XMP · MakerNotes
  └────────┬─────────┘
           ▼
  ┌──────────────────┐
  │ inspector panel  │  every tag, grouped, human-readable
  └────────┬─────────┘
           ▼
     user selects ────► ☑ GPS  ☐ EXIF  ☑ MakerNotes
           │
           ▼
  ┌──────────────────┐
  │ write clean copy │  originals untouched
  └────────┬─────────┘
           ▼
     ✅ done — 100% local, nothing left the machine
```

| Capability | Free | PRO (€9.99 once) |
|---|---|---|
| Inspect all metadata | ✅ | ✅ |
| Remove all metadata | ✅ | ✅ |
| Remove GPS only | ✅ | ✅ |
| JPG · PNG · HEIC · TIFF · MOV · MP4 | ✅ | ✅ |
| Per-category selective removal | — | ✅ |
| Folder batch processing | — | ✅ |
| Export metadata (CSV/JSON) first | — | ✅ |
| Before/after comparison | — | ✅ |
| Preset profiles | — | ✅ |
| RAW formats (CR2, CR3, ARW, NEF, ORF, DNG) | — | ✅ |
| Watch folder — auto-clean on arrival | — | ✅ |
| Undo with backed-up originals | — | ✅ |

The free tier must be **genuinely useful alone** — inspection and one-click
GPS removal solve the common case. PRO sells control, not access.

## 🏗️ Architecture

| Layer | Choice | Why |
|---|---|---|
| UI | Swift + SwiftUI | Native drag-and-drop, sandbox-friendly |
| Engine | Bundled ExifTool v13.57 | The reference implementation; nothing else comes close |
| Processing | Fully local | The privacy claim is void if anything uploads |
| Licensing | One-time key, offline check | No subscription, no account |
| Distribution | Signed + notarized `.app` | Gatekeeper must not warn |

## ⚠️ Risks

- 🍎 **macOS only** — the native-feel advantage is also the ceiling. Cross-platform is **MetaStrip** (VC-007)'s job, not this one.
- 🔄 ExifTool needs updating as formats appear — bundle a version, plan the update path
- 📸 RAW support varies by vendor; test per camera, never assume
- 💸 Gating too much behind PRO kills free-tier adoption, which is the funnel
