> 🗺️ **Devoluto is a public, crowd-sourced map of empty state-owned buildings
> in Portugal** — houses, schools, barracks, warehouses — that could be turned
> into public housing. Anyone can look. Anyone who registers can add one.

Portugal has a housing crisis and, at the same time, a long tail of public
buildings standing empty: closed schools, decommissioned barracks, old
railway houses, ministry warehouses. Nobody holds a single, current, visible
list of them. Devoluto builds that list from the ground up — people who walk
past these buildings every day pin them on a map, describe them, and the
aggregate turns into evidence.

---

## ⚙️ How It Works

```
   👤 registered contributor                 👀 anonymous visitor
        │                                          │
        │ pin on map ──or── type GPS coords        │ browse · filter · stats
        ▼                                          │
  ┌──────────────────────────────┐                 │
  │ 1. Place the point           │  snap to the    │
  │    satellite / street layer  │  building roof  │
  └──────────────┬───────────────┘                 │
                 ▼                                 │
  ┌──────────────────────────────┐                 │
  │ 2. Auto-fill location        │  distrito ·     │
  │    point-in-polygon on CAOP  │  concelho ·     │
  └──────────────┬───────────────┘  freguesia      │
                 ▼                                 │
  ┌──────────────────────────────┐                 │
  │ 3. Duplicate check           │  "3 pins within │
  │    existing pins ≤ 50 m      │   50 m — same?" │
  └──────────────┬───────────────┘                 │
                 ▼                                 │
  ┌──────────────────────────────┐                 │
  │ 4. Fill the form             │  type · floors ·│
  │    + optional photos         │  fractions · …  │
  └──────────────┬───────────────┘                 │
                 ▼                                 ▼
  ┌─────────────────────────────────────────────────────┐
  │        SQLite   ·  every edit versioned              │
  └──────────────┬───────────────────────┬──────────────┘
                 ▼                       ▼
         🗺️ public map            📊 statistics + open-data export
```

The three territories sit far apart, so the map opens on the mainland with
**Açores** and **Madeira** as clickable insets, the way official Portuguese
maps draw them — one click jumps to each archipelago at full zoom.

## 🧾 What a Pin Records

| Field | Type | Why it matters |
|---|---|---|
| 📍 Location | Point (lat/lon) | Placed on the map or typed as GPS coordinates |
| 🏷️ Property type | House · apartment block · school · barracks · hospital · warehouse · office · railway building · other | The first filter everyone reaches for |
| 🏢 Floors | Integer | Rough capacity |
| 🚪 Fractions | Integer, or "unknown" | The number that matters most for housing |
| 🕰️ Former use | Free text + category | A school converts differently from a warehouse |
| 🏛️ Suspected owner | State · municipality · public company · military · unknown | Who would have to act |
| 🔎 Ownership evidence | Signage · public record link · local knowledge | How sure the contributor is |
| 🧱 Condition | Good · needs repair · ruin | Separates quick wins from long projects |
| ⏳ Vacant since | Year, approximate | Long vacancy is the strongest argument |
| 📐 Approx. area | m², optional | Helps estimate housing potential |
| 📷 Photos | Up to 5, exterior only | Proof the building exists and is empty |
| 📝 Notes | Free text | Anything else |

Distrito, concelho and freguesia are **never typed** — they are computed from
the point, so the statistics can never disagree with the map.

## 👥 Who Can Do What

| | 👀 Visitor | ✍️ Contributor | 🛡️ Moderator |
|---|---|---|---|
| Browse map, filter, see stats | ✅ | ✅ | ✅ |
| Download open data (CSV / GeoJSON) | ✅ | ✅ | ✅ |
| Add a pin | — | ✅ | ✅ |
| Edit own pin, confirm or dispute others | — | ✅ | ✅ |
| Merge duplicates, hide abuse, verify | — | — | ✅ |

Registration is an email magic link — no password to forget, and one verified
address per account keeps spam manageable.

Pins carry a trust status that the map shows by colour:

```
  🟡 reported ──► 🟠 confirmed by 2+ others ──► 🟢 verified (moderator / public record)
        │
        └──► ⚫ disputed  (someone says it is occupied, private, or gone)
```

## 📊 Statistics

Aggregates update live and respect whatever filter is active on the map.

- 🧮 **Totals** — buildings mapped, estimated fractions, verified share
- 🗺️ **Choropleth** by distrito and concelho — where the empty stock is
- 🏷️ **Breakdown** by property type, former use, suspected owner and condition
- ⏳ **Vacancy age** — how long buildings have been empty
- 📈 **Growth** — pins added per month, to show the map is alive

Every chart can be exported, and the whole dataset is downloadable — the
point is for journalists, researchers and municipalities to reuse it.

## 🧰 Stack

| Layer | Choice | Note |
|---|---|---|
| Map library | MapLibre GL JS | Renders vector PMTiles natively and accepts a WMS raster layer; Leaflet would need plugins for both |
| Base map | Protomaps PMTiles, self-hosted | One OSM-based file for mainland, Açores and Madeira, served by nginx from our own server: no API key, no usage limits, no tracking. Styled with `@protomaps/basemaps`. **OpenFreeMap** (`https://tiles.openfreemap.org/styles/liberty`) is the drop-in fallback |
| Aerial layer | DGT OrtoSat 2023 (WMS) | Official 30 cm true-colour satellite orthophotos, open, CORS-enabled. **Mainland only** — see Map & Data Sources |
| Boundaries | CAOP 2025 (DGT) | Converted once to WGS84 GeoJSON; used for point-in-polygon and the per-concelho table |
| Backend | Python 3.12 + FastAPI + uvicorn | One process behind nginx; `shapely` for geometry, `pyproj` not needed at runtime |
| Database | SQLite (WAL mode) | One file outside the web root; backed up with `sqlite3 .backup` |
| Email | Any SMTP provider | Only sends magic links |
| Frontend | Plain HTML + vanilla JS + CSS | No build step, Portuguese labels |

## 🗺️ Map & Data Sources

All of these were checked on 2026-10-29.

| Source | Where | Notes |
|---|---|---|
| Base map tiles | `https://build.protomaps.com/YYYYMMDD.pmtiles` | Daily planet builds (~139 GB). Never download it whole — `pmtiles extract` pulls only Portugal over HTTP. Old builds are deleted, so pick a recent date |
| Aerial, mainland | `https://ortos.dgterritorio.gov.pt/wms/ortosat2023` | WMS 1.3.0, layer `ortoSat2023-CorVerdadeira`, supports `EPSG:3857`, PNG, `Access-Control-Allow-Origin: *`. Covers longitude −10.19 to −5.71 only |
| Aerial, Madeira | iRIG-Madeira (DROTA) geoservices | 2018/19 orthophotos at 10 cm exist, licence CC BY *non-commercial*. Endpoint not confirmed yet — after the MVP |
| Aerial, Açores | IDEA catalogue (`sma.idea.azores.gov.pt`) | Per-island WMS/WMTS services of varying age. Not confirmed yet — after the MVP |
| Boundaries, mainland | `https://geo2.dgterritorio.gov.pt/caop/CAOP_Continente_2025-gpkg.zip` | ~112 MB GeoPackage |
| Boundaries, Madeira | `https://geo2.dgterritorio.gov.pt/caop/CAOP_RAM_2025-gpkg.zip` | Layers `ram_distritos`, `ram_municipios`, `ram_freguesias`; EPSG:5016 |
| Boundaries, Açores | `https://geo2.dgterritorio.gov.pt/caop/CAOP_RAA_2025-gpkg.zip` | Split into island groups with their own UTM zones |

CAOP freguesia layers carry `dtmnfr` (the 6-digit DICOFRE code), `freguesia`,
`municipio` and `distrito_ilha` — on the islands the "district" column holds
the **island name**, so the UI labels that level *Distrito / Ilha*. Check
layer names with `ogrinfo` before converting; only the Madeira file was
inspected.

On the islands the MVP has no aerial layer: contributors place the pin on
the base map, which shows building outlines at high zoom.

Map attribution, always visible: *© OpenStreetMap contributors · Protomaps ·
OrtoSat 2023 © DGT · CAOP 2025 © DGT*.

## 🗄️ Data Model

```sql
PRAGMA journal_mode = WAL;
PRAGMA foreign_keys = ON;

CREATE TABLE users (
  id          INTEGER PRIMARY KEY,
  email       TEXT NOT NULL UNIQUE COLLATE NOCASE,
  role        TEXT NOT NULL DEFAULT 'contributor'
              CHECK (role IN ('contributor', 'moderator')),
  created_at  TEXT NOT NULL DEFAULT (datetime('now')),
  banned_at   TEXT
);

CREATE TABLE login_tokens (           -- magic links: single use, 15 min
  token_hash  TEXT PRIMARY KEY,       -- sha256 of the token, never the token
  user_id     INTEGER NOT NULL REFERENCES users(id),
  expires_at  TEXT NOT NULL,
  used_at     TEXT
);

CREATE TABLE sessions (               -- 30-day HttpOnly cookie
  id          TEXT PRIMARY KEY,       -- random 32 bytes, urlsafe
  user_id     INTEGER NOT NULL REFERENCES users(id),
  expires_at  TEXT NOT NULL
);

CREATE TABLE pins (
  id                  INTEGER PRIMARY KEY,  -- shown as DEV-000123, never reused
  lat                 REAL NOT NULL,
  lon                 REAL NOT NULL,
  region              TEXT NOT NULL CHECK (region IN ('continente', 'acores', 'madeira')),
  dicofre             TEXT NOT NULL,        -- 6-digit CAOP code
  distrito            TEXT NOT NULL,        -- island name on Açores/Madeira
  concelho            TEXT NOT NULL,
  freguesia           TEXT NOT NULL,
  property_type       TEXT NOT NULL,
  floors              INTEGER,
  fractions           INTEGER,              -- NULL = unknown
  former_use_category TEXT,
  former_use_text     TEXT,
  suspected_owner     TEXT NOT NULL,
  ownership_evidence  TEXT NOT NULL,
  evidence_url        TEXT,
  condition           TEXT NOT NULL,
  vacant_since        INTEGER,              -- year, approximate
  area_m2             INTEGER,
  notes               TEXT,
  status              TEXT NOT NULL DEFAULT 'reported'
                      CHECK (status IN ('reported', 'confirmed', 'verified', 'disputed', 'hidden')),
  created_by          INTEGER NOT NULL REFERENCES users(id),
  created_at          TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at          TEXT NOT NULL DEFAULT (datetime('now'))
);
CREATE INDEX pins_latlon   ON pins(lat, lon);
CREATE INDEX pins_concelho ON pins(concelho);

CREATE TABLE pin_versions (           -- full snapshot before every change
  id          INTEGER PRIMARY KEY,
  pin_id      INTEGER NOT NULL REFERENCES pins(id),
  data        TEXT NOT NULL,          -- JSON of the old row
  changed_by  INTEGER NOT NULL REFERENCES users(id),
  changed_at  TEXT NOT NULL DEFAULT (datetime('now')),
  reason      TEXT                    -- 'edit', 'verify', 'hide', ...
);

CREATE TABLE reactions (              -- one per user per pin
  pin_id      INTEGER NOT NULL REFERENCES pins(id),
  user_id     INTEGER NOT NULL REFERENCES users(id),
  kind        TEXT NOT NULL CHECK (kind IN ('confirm', 'dispute')),
  reason      TEXT,                   -- required for a dispute
  created_at  TEXT NOT NULL DEFAULT (datetime('now')),
  PRIMARY KEY (pin_id, user_id)
);
```

Coded values are stored in English and labelled in Portuguese in the UI:

| Field | Codes → labels |
|---|---|
| `property_type` | `house` Moradia · `apartment_block` Prédio · `school` Escola · `barracks` Quartel · `hospital` Hospital / centro de saúde · `warehouse` Armazém · `office` Escritórios · `railway` Edifício ferroviário · `other` Outro |
| `suspected_owner` | `state` Estado · `municipality` Câmara municipal · `public_company` Empresa pública · `military` Forças Armadas · `unknown` Desconhecido |
| `ownership_evidence` | `signage` Placa no local · `public_record` Registo público (link) · `local_knowledge` Conhecimento local |
| `condition` | `good` Bom · `needs_repair` Precisa de obras · `ruin` Ruína |
| `former_use_category` | `housing` Habitação · `education` Ensino · `health` Saúde · `military` Militar · `transport` Transportes · `administration` Administração · `industry` Indústria · `other` Outro |

**Status rules**, applied by the backend after every reaction:

- any open dispute → `disputed`, until a moderator resolves it
- otherwise 2 or more confirmations from users other than the creator → `confirmed`
- `verified` and `hidden` are set only by a moderator; `hidden` pins never
  appear in the map, statistics or export

## 🔌 API

All responses are JSON; write routes need the session cookie and a CSRF
header (`X-Requested-With: devoluto`).

| Method and path | Who | Does |
|---|---|---|
| `GET /api/pins?bbox=&type=&condition=&owner=&status=` | anyone | Visible pins as GeoJSON for the current view and filters |
| `GET /api/pins/{id}` | anyone | One pin, with confirm / dispute counts |
| `GET /api/locate?lat=&lon=` | anyone | Region, distrito, concelho, freguesia — or 422 if outside Portugal |
| `GET /api/nearby?lat=&lon=` | anyone | Pins within 50 m, nearest first |
| `POST /api/pins` | contributor | Create; returns the new `DEV-` id |
| `PATCH /api/pins/{id}` | creator or moderator | Edit; snapshot goes to `pin_versions` |
| `POST /api/pins/{id}/react` | contributor | `{kind: confirm or dispute, reason}`; not on own pins |
| `POST /api/pins/{id}/moderate` | moderator | `{action: verify, hide, unhide, resolve_dispute}` |
| `GET /api/stats?…same filters…` | anyone | Totals, sum of fractions, counts by type, condition, owner, concelho |
| `GET /api/export.csv` · `/api/export.geojson` | anyone | Full dataset of visible pins, no user data |
| `POST /api/auth/request-link` | anyone | `{email}`; always answers 200, so emails can't be probed |
| `GET /api/auth/verify?token=` | anyone | Consumes the link, sets the cookie, redirects to the map |
| `POST /api/auth/logout` | contributor | Ends the session |

**Limits:** 10 new pins and 5 login emails per account per day; 3 login
emails per IP per hour.

**Duplicate check:** select candidates with a box of ±0.0005° latitude and
±0.0007° longitude (a bit more than 50 m in Portugal), then keep those whose
haversine distance is ≤ 50 m.

**Locate:** at startup load the CAOP freguesia GeoJSON into a
`shapely.STRtree`; a lookup is one `query(point, predicate="within")`.

## 🛠️ One-time Data Setup

```bash
# 1. Base map — Portugal + Açores + Madeira in one file (several hundred MB)
#    https://github.com/protomaps/go-pmtiles/releases  → pmtiles binary
pmtiles extract https://build.protomaps.com/20261028.pmtiles data/portugal.pmtiles \
  --bbox=-31.6,29.9,-6.1,42.3

# 2. Boundaries — needs GDAL (apt install gdal-bin)
for r in Continente RAM RAA; do
  curl -O https://geo2.dgterritorio.gov.pt/caop/CAOP_${r}_2025-gpkg.zip
  unzip -o CAOP_${r}_2025-gpkg.zip -d caop_src/
done
ogrinfo caop_src/*.gpkg            # list layers: *_freguesias, *_municipios
# for every *_freguesias layer:
ogr2ogr -f GeoJSON -t_srs EPSG:4326 -lco COORDINATE_PRECISION=6 \
  data/caop/<layer>.geojson caop_src/<file>.gpkg <layer>
```

The bounding box spans from the Flores island in the west to the Spanish
border in the east, and down to the Selvagens. Ocean tiles are nearly empty,
so they add little to the file size.

## 🚀 Hosting

```
  browser ──► nginx ─┬─ /                → frontend/        (static)
                     ├─ /tiles/*.pmtiles → data/            (static, Range requests)
                     └─ /api/            → uvicorn 127.0.0.1:8000  (systemd)
                                              │
                                              ▼
                             /var/lib/devoluto/devoluto.db   (outside the web root)
```

- nginx serves the `.pmtiles` file as a plain static file — Range requests
  work out of the box; add `Access-Control-Allow-Origin` only if the map is
  served from another host
- the SQLite file lives in `/var/lib/devoluto/`, owned by the service user —
  never inside a directory that a deploy rsyncs with `--delete`
- `backup.sh` from cron nightly; copy the backup off the server
- HTTPS is required — the session cookie is `Secure; HttpOnly; SameSite=Lax`

## ⚠️ Risks

- ⚖️ **Wrong ownership is the biggest risk.** Labelling a private house as
  "empty state property" invites trespass and complaints — the form must say
  *suspected*, ask for evidence, and make disputing easy
- 🔒 **Privacy and GDPR** — no photos of people or plates, no interiors,
  contributor identities never public (exports carry no user data), a clear
  takedown route by email
- 🚷 **Safety** — tell contributors plainly not to enter buildings or private land
- 🗑️ **Spam and vandalism** — rate limits, the confirmation threshold, moderator tools
- 🧭 **Pin accuracy** — GPS from a phone on the street lands on the street;
  the aerial layer and a "drag to the roof" step fix most of it on the
  mainland. The islands have no aerial layer in the MVP
- 🗺️ **Map hosting** — the PMTiles file has to be re-extracted now and then
  to stay current; if self-hosting becomes a burden, switch the base map to
  OpenFreeMap without touching anything else. The DGT service can be slow,
  so the aerial layer is off by default and switched on when placing a pin
- 📡 **Third-party endpoints move** — DGT URLs change between editions
  (the 2021 service now returns blank images). Keep every external URL in
  one config file

## ✅ Definition of Done (MVP)

A visitor with no account opens the site on a phone, jumps to Madeira, filters
for *schools in poor condition*, and sees the pins and a per-concelho count.
A registered contributor in Porto pins a closed school in under two minutes:
switches on the aerial layer, drags the pin onto the roof, sees *Porto ·
Cedofeita…* filled in automatically, and is warned about a duplicate 30 m
away. Two other contributors confirm it and its colour turns orange. The
statistics include the new pin as soon as it is saved, and the full dataset
downloads as GeoJSON with no email addresses in it.
