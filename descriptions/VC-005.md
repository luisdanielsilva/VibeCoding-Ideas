> 🏘️ **PropInsight is the market's memory.** It collects listings, keeps every
> run as a timestamped snapshot, and answers what is for sale, at what price,
> for how long, and what has changed. It never decides what any of it is worth.

That refusal is the design. Scrapers die by growing into valuation products
before they can reliably fetch a page. This one stops at the evidence, and
hands judgement to **DealScope (VC-011)**.

## 🧩 The Common Schema

Every portal, however it publishes, normalizes to one row:

| Field | Notes |
|---|---|
| `price` | Asking price, currency-normalized |
| `price_per_sqm` | Derived when absent |
| `location` | Locality + coordinates where available |
| `property_type` | Apartment · house · plot · building |
| `area_sqm` | Units normalized on the way in |
| `rooms` | Typology (T1, T2, …) |
| `condition` | New · used · for renovation |
| `floor` | Matters more than it looks — price ladders by floor |
| `listing_date` | First seen, if the portal hides it |
| `url` | 🔑 provenance — every row traceable to its page |
| `fetched_at` | 🔑 provenance — when this was true |

## 📈 What Repetition Buys You

A single scrape gives a price list. **Repeated scrapes give a market.** These
metrics fall out of snapshot history and cannot be obtained any other way:

| Metric | Derived from | Answers |
|---|---|---|
| 💸 Price-cut rate | Same URL, lower price | Is this market softening? |
| ⏱️ Days on market | First seen → still listed | How long does stock sit? |
| 📉 Absorption rate | Listings disappearing per month | How fast does it actually sell? |
| 🆕 New-supply rate | Listings appearing per month | Is competition rising? |
| 📊 Price distribution | All live comps | Where does one asking price rank? |

> 💡 **Absorption is the developer's number.** How long 20 new units take to
> sell is a function of how fast this micro-market absorbs stock — and that is
> only observable by watching listings vanish over months. DealScope's sell-out
> schedule consumes exactly this.

---

## 🔌 The Query API

Two calls. This is the entire contract with VC-011:

| Call | Returns |
|---|---|
| `listing(url)` | One normalized property record |
| `comparables(subject, rules)` | Matching rows + median €/m², spread, subject percentile, velocity stats |

Matching is by rule, never by eye: same locality or a radius around the
coordinates, same typology, area within a tolerance band, comparable
condition, listed recently enough to still reflect the market.

> ⚠️ **Report the sample size and decline when it's thin.** Six comparables
> spread across four neighbourhoods cannot support a conclusion. Returning
> "insufficient comparables" is a correct answer; inventing confidence is not.

## 👥 Who Uses It Directly

- 🏠 **A buyer** tracks a neighbourhood for months before making an offer, and sees which listings cut their price and by how much
- 🏗️ **A developer** sizes the competing supply for a site: what is already listed nearby, at what €/m², and how quickly it clears
- 🔁 **DealScope** consumes both through the query API

## 🌍 The Proxy Layer

Pluggable, because two real problems demand it:

1. 🚫 Large portals block whole datacenter IP ranges outright — politeness doesn't help
2. 🗺️ Many portals serve different prices, currency or inventory by visitor country — scraping a foreign market accurately means exiting from it

> ⚠️ **Proxies are routing, not permission.** Rate limits, delays and
> concurrency caps apply **per target**, regardless of pool size — adding
> proxies never increases the load any single portal sees.

## ⚠️ Risks

- 🛡️ Anti-scraping: rate limits, CAPTCHAs, IP blocks
- 🔧 Redesigns silently break selectors → **alerting is not optional**
- 💰 Residential proxies are a recurring per-GB cost, varying in quality and sourcing ethics
- 📜 Terms-of-service and data-reuse rules differ per site
- 🧹 Dirty source data: missing areas, mixed units, duplicates
- 👥 The same property relisted by several agencies inflates every count — dedupe before any statistic is computed
- 🏷️ **These are asking prices, not sold prices.** Every consumer of this data must be told so.
